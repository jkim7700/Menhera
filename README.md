# Menhera
# 부재중 47통

불안이 큰 사람과 사귀는 텍스트 연애 스릴러 게임입니다. 일곱 번의 순간, 열네 번의 선택으로 연인이 되거나 헤어지고, 헤어진 뒤의 밤까지 이어집니다.

- 게임은 `index.html` 하나이고 빌드 과정이 없습니다. `worker/`는 Claude API 연결용 선택 사항입니다.
- 그녀의 단계는 1~3단계 중에서 고릅니다. 단계가 높을수록 한마디에 터지는 불안과 집착이 강해지고, 한 번의 실수가 끝으로 이어질 수 있습니다.
- 만나는 곳은 모교 축제(고등학교), PC방, 길거리, 심야 편의점, 코인노래방, 만화카페 중 고릅니다. 등장인물은 모두 성인입니다.
- 선택지를 고르거나 직접 말을 입력할 수 있습니다.

## 게임 구조

지표는 세 가지입니다.

| 지표 | 의미 |
| --- | --- |
| 호감 | 그녀가 얼마나 마음을 여는지 |
| 안정 | 그녀의 불안이 얼마나 가라앉았는지 |
| 내 여유 | 내가 얼마나 버틸 수 있는지. 다 받아주기만 하면 줄어듭니다 |

`오늘은 어제랑 좀 다르네` 같은 악의 없는 한마디도 불안한 사람에게는 사랑이 식었다는 신호가 되어, `나 이제 안 예뻐? 나 안 사랑해? 나 싫어?`처럼 몰아붙이는 반응을 부릅니다.

엔딩은 호감, 안정, 내 여유로 갈립니다.

- 함께 나아지는 엔딩, 위태로운 연인 엔딩, 지친 연인 엔딩, 친구로 남은 엔딩, 거절 엔딩
- 내 여유가 바닥나면 번아웃 엔딩, 그녀의 안정이 바닥나면 연락 두절 엔딩
- 연인이 된 뒤에는 이별을 말할 수 있고, 말하는 방식에 따라 정리된 이별, 연락 폭주, 폭로, 잠복, 위협, 끝나지 않는 이별, 데드엔딩으로 갈라집니다.

## GitHub Pages로 배포하기

1. 새 저장소를 만들고 `index.html`, `README.md`를 올립니다.
2. 저장소의 Settings > Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.

로컬에서는 `index.html`이 있는 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 열면 됩니다.

## 직접 입력 반응에 Claude API 연결하기

기본 상태(`API_URL`이 빈 값)에서는 직접 입력한 말을 키워드로 읽는 기본 반응으로 진행합니다. Claude 앱 안에서 열면 별도 설정 없이 Claude가 즉석 반응을 만들어 줍니다.

GitHub Pages에서도 Claude 반응을 쓰려면 API 키를 숨겨 주는 중계 서버가 필요합니다. 키를 `index.html`에 넣으면 누구나 훔쳐 쓸 수 있으므로 절대 넣지 마세요. `worker/`는 무료로 쓸 수 있는 Cloudflare Worker 예시입니다.

1. [Anthropic Console](https://platform.claude.com)에서 API 키를 만들고, 사용 한도(spend limit)를 낮게 걸어 둡니다.
2. `worker/wrangler.toml`의 `ALLOWED_ORIGIN`에서 `<사용자명>`을 본인 GitHub 사용자명으로 바꿉니다.
3. `worker/` 폴더에서 다음을 실행합니다.

   ```bash
   npx wrangler login
   npx wrangler secret put ANTHROPIC_API_KEY   # 키를 붙여 넣기
   npx wrangler deploy
   ```

4. 배포가 끝나면 `https://missed-calls-proxy.<계정>.workers.dev` 같은 주소가 나옵니다. 이 주소를 `index.html`의 `var API_URL="";` 안에 넣고 다시 커밋합니다.

주의할 점은 다음과 같습니다.

- `ALLOWED_ORIGIN` 검사는 다른 사이트의 브라우저 호출을 막을 뿐, 직접 요청을 보내는 사람까지 막지는 못합니다. Cloudflare의 Rate limiting 규칙을 걸고 Anthropic 사용 한도를 낮게 유지하세요.
- 기본 모델은 빠르고 저렴한 `claude-haiku-5-5`입니다. 대사 품질을 높이려면 `wrangler.toml`의 `MODEL`을 `claude-sonnet-5-5`로 바꿉니다.
- 중계 서버가 실패하거나 한도에 걸리면 게임은 자동으로 기본 반응으로 이어집니다.
- API 사용량은 키 소유자에게 과금됩니다. 자세한 내용은 [Claude API 문서](https://platform.claude.com/docs/en/api/messages)를 참고하세요.

## 내용 수정하기

`index.html` 안의 `<script>`에서 다음을 고치면 됩니다.

- `EVENTS`: 이벤트, 장면, 선택지, 단계별 대사
- `LEVELS`: 단계별 성격과 표정 묘사
- `PLACES`: 만나는 곳별 첫 만남 장면
- `TAGS`: 말투별 호감, 안정, 내 여유 변화량
- `ENDINGS`: 엔딩 문구

## 게임 밖 이야기

멘헤라는 의학 용어가 아니라 인터넷에서 쓰는 신조어입니다. 이 게임은 누군가를 조롱하려는 것이 아니라 불안이 큰 사람을 곁에서 어떻게 대할지 생각해 보는 허구의 이야기입니다. 위기 장면, 스토킹과 폭력을 암시하는 어두운 장면이 나옵니다.

실제로 마음이 힘들다면 자살예방 상담전화 109(24시간)에서 이야기할 수 있습니다. 위험이 임박했다면 112나 119에 바로 연락하세요.
